# haggle data

Public files for [haggle](https://haggle.hackclub.com), Hack Club's weekly machine learning competitions for teens.

## Week 1: Hour Detective

| File | What it is |
|---|---|
| `hour-detective/train.csv` | 4,500 real Hack Club projects and the hours a reviewer approved |
| `hour-detective/hour-detective-starter.zip` | The starter kit: notebook, `predict.py`, README and `train.csv` |

What every column means: [the Data tab](https://haggle.hackclub.com/competitions/hour-detective/data/). How to ship: [Your first ship](https://haggle.hackclub.com/guides/first-ship/).

Direct downloads are on the [Releases](../../releases) page.

## Please

- Don't try to find the people behind the rows.
- Don't upload `train.csv` to your own repo. The starter kit's `.gitignore` keeps it out.
